# Mide Simulator — Vercel

Игра работает **без ключа**: запускается сразу, диалоги шаблонные, но торг, цифры, встречи и продажи — как настоящие.

Живой ИИ включается, когда игрок вводит **свой** ключ DeepSeek в настройках (⚙ → «Ключ DeepSeek»).
Кто ключа не имеет — покупает у **@proxek_sell**.

## Структура

```
public/index.html   — игра (лента, чат, встречи, ремонт, продажи, настройки)
api/_core.js        — модель deepseek-flash, лимиты, общий код
api/ai.js           — диалоги (ключ игрока в заголовке X-Mide-Key)
api/checkkey.js     — проверка ключа игрока
api/limits.js       — остаток токенов
api/ping.js         — проверка живости
```

Старые файлы (auth, invoice, grant, pending, unlock) больше не используются — бот и оплата не нужны.

## Как работает

1. Игрок открывает ссылку — игра стартует сразу.
2. ⚙ → «Ключ DeepSeek» → вставляет свой ключ → «Проверить».
3. Если ключ рабочий — статус зелёный, диалоги становятся живыми.
4. Без ключа — шаблоны, но игра полностью проходима.
5. «Нет ключа? → Купить» открывает `https://t.me/proxek_sell`.

## Лимиты

- модель `deepseek-flash`, thinking выключен;
- 100 000 токенов в день на игрока;
- 2 000 000 в месяц на всех;
- при исчерпании — шаблоны.

## Деплой

Vercel → Add New → Project → Import Git Repository → **fizzzixs-group/mide-vercel** → Deploy.
Правки в GitHub сами пересобирают проект.
